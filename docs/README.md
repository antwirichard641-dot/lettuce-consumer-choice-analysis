# Reproducibility Guide

## Project Overview
This project analyzes consumer choices for hydroponic and organic lettuce using discrete-choice methods.

## Requirements
- Python 3
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- statsmodels

## Data
The cleaned dataset is stored in `datasets/lettuce_consumer_choice_clean.csv`.

## Workflow
1. Run `01_Consumer_Choice_Data_Preparation_and_Exploration.ipynb`.
2. Run `02_Consumer_Choice_Modeling_Hydroponic_Organic_Lettuce.ipynb`.
3. Run `03_Results_Visualization_and_Research_Conclusions.ipynb`.

## Reproducibility Notes
Run the notebooks in order. Verify that the reported statistical results and figures match the outputs generated from the cleaned dataset. Results should not be treated as final until the notebooks have been executed and checked.
